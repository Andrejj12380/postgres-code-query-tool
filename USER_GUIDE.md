# Руководство пользователя: MarkView

Инструмент для мониторинга, фильтрации и выгрузки кодов из баз данных PostgreSQL.

## 1. Установка и запуск
1. Запустите файл `MarkView-setup.exe`.
2. После установки на рабочем столе появится ярлык `MarkView`.
3. Приложение запускается в фоновом режиме. Интерфейс откроется в вашем браузере по умолчанию.

## 2. Настройка подключений
Перед началом работы необходимо добавить базы данных:
1. Перейдите в раздел **"Базы данных"** (🔌) в боковом меню.
2. Нажмите **"Добавить подключение"**.
3. Введите название, хост, порт, имя пользователя, пароль и название базы данных.
4. Нажмите **"Сохранить"**.

## 3. Настройка продукции (GTIN)
Чтобы фильтровать данные по конкретным товарам:
1. Перейдите в раздел **"Продукция"** (📦).
2. Добавьте название товара и его **GTIN** (обычно это первые цифры кода).
3. Нажмите **"Сохранить"**.

## 4. Настройка названий полей (Labels)
Вы можете изменить стандартные названия колонок базы данных на понятные вам:
1. Перейдите в раздел **"Названия полей"** (🏷️).
2. Введите свои названия (например, для `dtime_ins` можно написать "Дата Загрузки").
3. Нажмите **"Сохранить"**. Эти названия будут использоваться в визуальном интерфейсе и в заголовках Excel-файлов.

## 5. Поиск и отчеты
Основной экран **"Поиск и Отчеты"** (📊) позволяет:
- **Выбрать БД**: Выберите одну из настроенных баз.
- **Выбрать товар**: Можно искать по всем товарам или выбрать конкретный GTIN.
- **Период**: Выберите конкретную дату или диапазон дат.
- **Тип даты**: Выберите, по какому полю фильтровать (Дата производства или Дата вставки в БД).
- **Запросить данные**: Показывает краткую сводку по количеству найденных кодов.

## 6. Выгрузка данных (Excel / CSV)
После того как данные найдены:
1. В блоке **"Настройки выгрузки (поля)"** выберите, какие именно колонки должны попасть в отчет.
2. **Только новые (невыгруженные)**: 
   - Если включено, будут выгружены записи только со `status = 1`.
   - **ВАЖНО**: После успешной выгрузки Excel-файла, статус этих записей в базе данных автоматически изменится на `9`. Это нужно, чтобы избежать повторной выгрузки тех же самых кодов.
3. Нажмите кнопку **"Выгрузить детализацию (Excel)"** или **"CSV"** для скачивания файла.
4. Кнопка **"Скачать сводку"** позволяет быстро получить итоговые цифры (без детализации кодов).

## 7. Устранение неполадок
- **Белый экран**: Если после запуска виден только белый фон, попробуйте перезапустить приложение.
- **Ошибка "Can't write" при обновлении**: Убедитесь, что приложение закрыто (используйте ярлык "Stop Service" в меню Пуск) перед запуском нового установщика.
- **Не меняется статус**: Убедитесь, что при выгрузке включен тумблер "Только новые".
