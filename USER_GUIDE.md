# Руководство пользователя: MarkView

Инструмент для мониторинга, фильтрации и выгрузки кодов из баз данных PostgreSQL.

## 1. Установка и запуск
1. Запустите файл `MarkView-setup.exe`.
2. После установки на рабочем столе появится ярлык `MarkView`.
3. Приложение запускается в фоновом режиме. Интерфейс откроется в вашем браузере по умолчанию.

## 2. Настройка подключений
Перед началом работы необходимо добавить базы данных:
1. Перейдите в раздел **"Базы данных"** (🔌) в боковом меню.
2. Нажмите **"Добавить подключение"**.
3. Введите название, хост, порт, имя пользователя, пароль и название базы данных.
4. Нажмите **"Сохранить"**.

## 3. Настройка продукции (GTIN)
Чтобы фильтровать данные по конкретным товарам:
1. Перейдите в раздел **"Продукция"** (📦).
2. Добавьте название товара и его **GTIN** (обычно это первые цифры кода).
3. Нажмите **"Сохранить"**.

## 4. Настройка названий полей (Labels)
Вы можете изменить стандартные названия колонок базы данных на понятные вам:
1. Перейдите в раздел **"Названия полей"** (🏷️).
2. Введите свои названия (например, для `dtime_ins` можно написать "Дата Загрузки").
3. Нажмите **"Сохранить"**. Эти названия будут использоваться в визуальном интерфейсе и в заголовках Excel/CSV-файлов.

> Колонки, которые появились в таблице `codes` позже (новые поля в БД), попадают в этот список автоматически после выбора базы на экране **"Поиск и Отчеты"** и помечаются бейджем **"Из БД"**.

## 5. Поиск и отчеты
Основной экран **"Поиск и Отчеты"** (📊) позволяет:
- **Выбрать БД**: Выберите одну из настроенных баз.
- **Выбрать товар**: Можно искать по всем товарам или выбрать конкретный GTIN.
- **Тип даты**: Выберите, по какому полю фильтровать (Дата производства или Дата вставки в БД).
- **Период**: Выберите конкретную дату или включите тумблер **"Диапазон"** и укажите две даты.
- **Статус кода**: `1` — новые, `9` — выгруженные, "Все статусы" или произвольное значение ("Другой...").
- **Запросить данные**: Показывает сводку по количеству найденных кодов по каждому GTIN, а также количество кодов, не начинающихся с `01046` (строка "Подозрительные").
- **Сводка по агрегации**: если в таблице есть групповые коды, под результатами появится блок с количеством палет/коробов и неагрегированных штучек (см. раздел 7).

## 6. Выгрузка данных (Excel / CSV)
После того как данные найдены:
1. В блоке **"Настройки выгрузки (поля)"** выберите, какие именно колонки должны попасть в отчет.
   - Список полей загружается **напрямую из таблицы `codes`** выбранной базы, поэтому новые колонки появляются автоматически (с пометкой **"БД"**). Рядом с заголовком отображается количество найденных полей.
   - Если структуру таблицы изменили, пока приложение открыто, нажмите **"Обновить поля"**.
   - Если загрузить поля не удалось (например, нет связи с БД), показывается предупреждение и стандартный набор полей; кнопка **"Повторить"** повторяет попытку.
   - **"Выбрать все" / "Снять выделение"** переключает все поля сразу.
2. **"Пометить выгруженные в БД (статус 9)"**:
   - **ВАЖНО**: если тумблер включён, то после выгрузки у всех выгруженных записей в базе данных статус автоматически меняется на `9`. Это нужно, чтобы избежать повторной выгрузки тех же самых кодов.
   - Если тумблер выключен, выгрузка ничего в базе не меняет.
   - Чтобы выгружать только ещё не выгруженные коды, выберите в фильтре **"Статус кода"** значение `1 - Новые`.
3. Нажмите кнопку **"Выгрузить детализацию (Excel)"** или **"(CSV)"** для скачивания файла.
4. Кнопка **"Скачать сводку"** позволяет быстро получить итоговые цифры (без детализации кодов).

## 7. Агрегация (палеты, коробы, штучки)
Если в таблице `codes` заполнены групповые коды, то они образуют "матрёшку":

| Уровень | Поле | Что содержит |
|---|---|---|
| 3 (высший) | `sscc1` | несколько `sscc` |
| 2 | `sscc` | несколько `grcode` |
| 1 | `grcode` | несколько штучных кодов `code` |

Может быть один уровень агрегации или несколько — программа сама определяет, какие поля есть в вашей базе, и пропускает отсутствующие.

**Как открыть**
- В блоке **"Агрегация"** на экране "Поиск и Отчеты" нажмите **"Открыть дерево агрегации →"** — фильтры перенесутся автоматически.
- Либо перейдите во вкладку **"Агрегация"** (🗂️) и задайте фильтры (БД, продукция, период, статус) вручную, затем нажмите **"Показать агрегацию"**.

**Что есть на вкладке**
- **Плитки уровней**: количество контейнеров каждого уровня, штучек внутри и количество неагрегированных кодов. Клик по плитке меняет верхний уровень дерева (например, начать с коробов вместо палет).
- **Дерево**: нажмите стрелку ▸ у палеты или короба — раскроется его содержимое (вложенные контейнеры или штучные коды). Данные подгружаются при раскрытии. В заголовке указано, сколько узлов показано из общего числа (отображается до 500 верхних узлов).
- **Поиск по любому коду**: введите или отсканируйте код штучки, короба или палеты. Программа покажет цепочку "палета › короб › штучка" и состав найденного контейнера. Если точного совпадения нет, будет предложен список частичных совпадений. Поиск идёт по всей базе и **не учитывает** фильтры по дате.
- **Проверка аномалий**:
  - штучки без единого группового кода (не агрегированы);
  - есть код низшего уровня, но не указан верхний (например, короб есть, а палеты нет);
  - контейнеры с нетиповым наполнением (например, в коробе 8 штучек, когда обычно 12). Типичным считается самое частое значение; проверка срабатывает, когда в выборке не менее 3 контейнеров уровня. Клик по коду открывает его состав.
- **Выгрузка**: кнопка **"⬇ Выгрузить состав"** у любого узла, **"⬇ Выгрузить всё"** для всей выборки и кнопки у групп аномалий. Формат (Excel или CSV) выбирается рядом с деревом.

## 8. Печать
Вкладка **"Печать"** (🖨️) показывает остатки ещё не напечатанных кодов (статус `0`):
1. Выберите базу данных и продукцию.
2. При необходимости задайте **срок годности** в днях — более старые коды не попадут в статистику.
3. Нажмите кнопку запроса статистики и при необходимости **"Скачать сводку"** (Excel).

## 9. Обслуживание (удаление кодов)
Вкладка **"Обслуживание"** (🛠️) нужна для удаления кодов из базы по фильтрам (период, продукция, статус, часть кода).

> ⚠️ **Удаление необратимо.** Всегда сначала нажмите **"Найти (кол-во)"** или **"Показать список"** и проверьте результат.

1. Задайте фильтры и нажмите **"Найти (кол-во)"** — программа покажет количество подходящих записей.
2. **"Показать список"** выводит до 500 найденных кодов, в нём можно отметить конкретные записи.
3. Нажмите **"Удалить ВСЕ найденные"** или **"Удалить выбранные"**.
4. Для подтверждения введите слово **УДАЛИТЬ** большими буквами.

## 10. Справка и обновления
- Кнопка **"Справка"** (❓) в боковом меню запускает интерактивный тур по всем разделам.
- Версия программы указана в левом верхнем углу бокового меню. Когда выходит новая версия, вверху экрана появляется баннер обновления.

## 11. Устранение неполадок
- **Белый экран**: Если после запуска виден только белый фон, попробуйте перезапустить приложение.
- **Ошибка "Can't write" при обновлении**: Убедитесь, что приложение закрыто (используйте ярлык "Остановить сервис" в меню Пуск) перед запуском нового установщика.
- **Не меняется статус при выгрузке**: Убедитесь, что включён тумблер **"Пометить выгруженные в БД (статус 9)"**.
- **Новой колонки нет в списке полей**: нажмите **"Обновить поля"**; проверьте, что колонка находится именно в таблице `codes` выбранной базы.
- **Нет вкладки/блока с агрегацией или нули в плитках**: в таблице `codes` отсутствуют поля `sscc1`/`sscc`/`grcode` либо они не заполнены за выбранный период.
- **Поиск по коду в "Агрегации" ничего не находит**: проверьте, что выбрана правильная база; поиск не зависит от дат и ищет по всей таблице.
